# Фото в PDF

Простой конвертер фото в PDF для Android: выбрал картинки → нажал «Собрать» → получил один PDF-файл. Со сканером документов, редактором, эффектами и бережной монетизацией (одна реклама только после кнопки «Собрать»).

Готовится к публикации в [RuStore](https://www.rustore.ru/).

## Возможности

- Выбор фото из галереи или съёмка камерой прямо в приложении
- Порядок страниц перетаскиванием (long-press)
- Редактор: поворот, обрезка рамкой, 16 цветовых эффектов, яркость/контраст/насыщенность, виньетка, магическое свечение
- Скан документов: 4 угла на углы листа, выпрямление перспективы, усиление «как сканер»
- Настройки PDF: A4 / по фото, ориентация, поля, качество, Ч/Б-режим
- Точный предпросмотр (рендер настоящего PDF) перед сборкой
- Сохранение в свою папку «Загрузки/PDFcon», шаринг, открытие
- Тёмная/светлая тема (или как в системе)

## Сборка

Открыть папку в Android Studio и нажать Run, либо из командной строки:

```
.\gradlew.bat :app:assembleDebug      # отладка
.\gradlew.bat :app:assembleRelease    # релиз (нужен ключ, см. ниже)
.\gradlew.bat :app:bundleRelease      # AAB для стора
```

Требования: JDK 17, Android SDK (compileSdk 36, minSdk 26).

### Релизная подпись

Ключ `pdfcon-release.jks` и пароли в `local.properties` не коммитятся
(см. `.gitignore`). Потеря ключа = невозможность обновлять приложение в сторе,
бэкап обязателен.

## Монетизация

Один interstitial РСЯ после кнопки «Собрать» (сборка PDF идёт параллельно).
ID блока — `core/ads/AdManager.kt` (`AD_UNIT_ID`).

## Конфиденциальность

Фото и PDF обрабатываются только на устройстве и никуда не отправляются.
Подробности: [PRIVACY.md](PRIVACY.md).
